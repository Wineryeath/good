# AGI-X Roadmap

## M0 — Reliable core (current)
- [x] Domain models and task lifecycle
- [x] Bounded orchestration loop
- [x] Approval policy boundary
- [x] SQLite event memory
- [x] Unit tests and CLI scaffold
- [ ] CI workflow and coverage baseline
- [ ] Structured logging and configuration validation

## M1 — Real intelligence integration
- [ ] Provider-neutral LLM interface and at least one configured provider
- [ ] Structured plan generation with schema validation
- [ ] Tool registry with schemas, timeouts and per-tool permissions
- [ ] Evidence-aware research adapter
- [ ] Independent result verification

## M2 — Long-running autonomy
- [ ] Persistent resumable task state
- [ ] Dependency-aware task graph and scheduler
- [ ] Retry policy, checkpoints, cancellation and resource budgets
- [ ] Human approval inbox and approval expiry
- [ ] Progress reporting and task dashboard

## M3 — Memory and learning
- [ ] Separate episodic, semantic, procedural and working memory
- [ ] Provenance, confidence, freshness and retention controls
- [ ] Retrieval evaluation and memory correction
- [ ] Learn reusable procedures from verified outcomes

## M4 — Advanced cognition
- [ ] Multi-model routing and specialist collaboration
- [ ] Hypothesis generation and adversarial critique
- [ ] Evidence-based verification and uncertainty reporting
- [ ] Benchmark suite for task success, reliability, cost and latency

## M5 — Governed capability evolution
- [ ] Capability registry and plugin contract
- [ ] Isolated build/test environment
- [ ] Regression, security and permission tests
- [ ] Versioned promotion, canary rollout and rollback
- [ ] Human approval for production changes and security policy changes

A milestone is complete only when tests and measurable acceptance criteria pass. A feature being implemented is not evidence that it works.
