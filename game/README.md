# 因果教廷 · 桌游数字化模拟器

《因果教廷》是一款 3–6 人本地热座策略桌游。玩家加入教廷、鬼、超凡者阵营，围绕 **律法、谎言、灵界** 三个世界维度争夺因果解释权。

## 开始游戏
无需安装、构建或联网：
1. 下载并打开 `index.html`。
2. 选择玩家人数、回合上限并填写名称。
3. 轮流使用同一设备。每位玩家行动前会私密展示阵营身份，请勿窥屏。

## 核心规则
- 每位玩家每回合最多执行 2 次行动。
- 影响力初始 3 点，上限 6 点；行动消耗影响力。结束回合恢复 1 点，每轮开始全体额外恢复 1 点。
- 三个维度范围为 0–10。
- 颁布律令：律法 +2、谎言 -1；散播谣言：谎言 +2、律法 -1；召唤异象：灵界 +2、律法 -1。
- 布置陷阱：设置监测维度、跨越阈值方向与触发效果。陷阱触发后失效，拥有者获得 1 点影响力。
- 调查因果：拆除一个陷阱并获得 1 点影响力；无陷阱可拆时获得 2 点影响力。
- 净化现实：三个维度各向 3 靠拢 1 点。
- 即时胜利：教廷（律法 ≥8 且灵界 ≤5）；鬼（谎言 ≥8 且律法 ≤5）；超凡者（灵界 ≥8 且律法、谎言均 ≤6）。
- 达到回合上限仍未即时获胜时，按主维度及附加条件加权结算。

## 实现
- `index.html`：完整单文件游戏，样式与逻辑均内置。
- 无第三方 JavaScript 库、外部服务或构建步骤。
- 游戏进度保存在当前浏览器 localStorage。
- 适用于现代桌面与移动浏览器。

本版本为可玩的数字化桌游原型。正式竞赛前建议玩家共同确认桌规与平衡性。
