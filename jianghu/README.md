# 一人一江湖 · Java 武侠人生模拟

> 一人一江湖，万般皆人生。

本目录的主开发路线为 **Java 17 + Gradle + LibGDX**。旧版浏览器原型文件仅作为早期设计留档，不是当前游戏入口，也不作为后续开发技术路线。

## 工程结构

- `core/`：纯 Java 游戏规则，包括世界时钟、玩家、地图、任务、NPC 日程、生活状态、玩家关系与 NPC 社会关系网络与家庭谱系。
- `lwjgl3/`：LibGDX 桌面客户端与渲染入口。
- `core/src/test/`：JUnit 5 自动化测试。
- `../.github/workflows/jianghu-java.yml`：自动执行核心测试与桌面端编译。

## 环境与运行

需要 JDK 17 和 Gradle 8.10.2 或兼容版本。在本目录执行：

```bash
gradle :core:test
gradle :lwjgl3:run
```

## 当前已实现

- 世界时钟：游戏日、时辰、分钟推进；玩家等待和移动会推动世界时间。
- 江南初始地图：地形碰撞、桥梁、水域、可交互地点与 NPC 位置。
- 玩家场景交互：按 F 与附近地点互动，可在河岸采集草药（每日每处一次、消耗体力），也可在听雨客栈付费休息并恢复健康与体力；集市和地标提供环境反馈。
- 玩家集市交易：在乌篷集市附近可按 B 购买草药、按 V 出售背包草药；交易使用江南区域供需报价，买入与卖出同步更新市场库存。
- 采药委托：按 J 接取三份草药交付任务，采集会自动累计进度，完成后再次按 J 交付物品并领取 180 文与声望；任务物品不足时不会扣除背包物品。
- NPC 生活互动：靠近有日程的 NPC 可按 K 打短工（消耗 15 体力、推进两小时并获得对应工钱），按 G 赠送一份背包草药；赠礼会消耗物品并影响 NPC 好感、信任与生活记忆。
- 分类背包与物品使用：按 I 打开行囊，按 1/2/3 使用熟食、清茶、金疮药；食物可缓解饥饿或口渴并恢复少量体力/心情，药品恢复健康。草药、粮食、鲜鱼等材料保留在背包，可用于委托、赠礼及后续制作；背包按食物、药品、材料、任务分类。
- 桌面 HUD：显示玩家健康、体力、银钱、草药库存、NPC 名称与附近地点交互提示；E 对话、F 地点交互、I 打开背包、1-4 使用物品、空格等待。
- NPC 日程：NPC 按时段在茶摊、集市、河埠、宅院等地点活动。
- NPC 人生状态：饥饿、精力、心情、职业收入与近期记忆按游戏小时结算；年龄按游戏日增长，每 360 天增长一岁，并划分童年、少年、成年、晚年阶段。
- 玩家关系：交谈会改变好感与信任，并记录 NPC 记忆。
- 玩家行为反馈：送礼、帮助、欺骗分别影响好感、信任、心情与记忆。
- NPC 社会网络：支持亲属、朋友、师徒、对手、仇敌等有类型的关系边，并限制关系强度范围。
- NPC 自主社交：关系双方在日程重叠、身处同一地点时，每个游戏日会发生一次相聚或争执，影响关系强度、心情并写入双方记忆。
- NPC 家庭系统：支持双向婚姻关系、父母与子女登记、兄弟姐妹和家庭成员查询；婚姻与添丁事件会同步社会关系、心情和人物记忆，并阻止重婚、未知成员及亲子循环。
- NPC 家庭事件：记录婚姻、添丁、冲突与和解的事件时间线；家庭成员可发生争执并暂时转为仇敌关系，也可通过和解恢复亲情关系，谱系本身不会因争吵而丢失。
- NPC 成长阶段：新登记的子女从 0 岁开始成长，NPC 随世界日期累计年龄，并在 12、18、60 岁等阶段节点留下成长记忆。
- 成年独立生活：年满 18 岁且存活的 NPC 可建立独立居所；仅在原日程回家时切换至新居，工作与外出安排保持不变，并记录人生记忆。
- NPC 健康与死亡：健康值可承受伤害，降至零时自动登记死亡事件；逝者停止日常结算与地图显示，但保留家庭谱系与人生记忆。
- NPC 疾病与治疗：NPC 可患有不同严重程度的疾病，病情会按游戏日损害健康；草药等治疗可降低病情并恢复健康，未及时救治的重症可能致死。
- 家族遗产继承：逝者的登记家庭成员可继承全部现有银钱，财产转移、继承记忆与家族事件时间线同步更新；重复添丁登记不会重复生成事件。
- 家族产业经营：NPC 可创办客栈、药铺与农庄，按游戏日结算营收、运营成本与员工工资；恶劣天气会压低营收，亏损可能形成产业债务。产业可升级至五级，提升营收同时增加运营成本；主人可将留存利润按比例分红给雇员。产业主人去世后由在世家庭成员继承，金库、债务、等级与其他雇员随产业保留。
- 江湖商品市场：客栈经营熟食、茶叶与鲜鱼，药铺经营草药与成药，农庄经营粮食与时蔬；产业可按当日市价采购库存并销售，自动核算库存成本与销售毛利。市场价格随游戏日期和天气波动。
- 区域供需与特产：江南、北岭、西蜀、东海、京城拥有不同的商品初始供给；采购会消耗当地现货并推高价格，销售会增加供给并压低价格。不同区域因此形成特产差异与跨区域套利空间，市场库存与需求状态由游戏世界持续保存。
- 行商商队：NPC 可组织商队、招募护卫与伙计，在出发地采购装载商品，按区域距离计算旅途时间，并在目的地按当地市价自动交货结算。商队有整备、行进、抵达、完成状态；暴雨、暴雪与台风可能造成绕路延误，特定商路也可能触发劫匪遭遇；遭遇结果由护卫武力决定，护卫薄弱时可能损失货物，并可能有最弱的一名护卫受伤；战斗伤害会实际扣除 NPC 健康值，严重时可能死亡并进入家族死亡事件。镖师、武师等高战力成员可显著降低损失甚至护住整支商队。伤员与全体成员都会留下旅途记忆，结算报告记录货物损失与净收益。
- Gradle + JUnit 5 测试与 GitHub Actions 持续集成。

## 设计中的后续内容

六大区域探索、武学战斗、门派、庭院经营、种田养殖、商贾与官场人生线、起兵称帝、隐藏逍遥路线以及多人联机仍需继续开发。当前 NPC 自主社交为确定性基础模拟：依据日程地点与关系类型触发每日互动；更复杂的事件传播、更完整的家族事件链、更丰富的疾病种类与医疗职业、NPC 自主决策、家庭成员迁居后的完整住所地图实体和持久化存档仍需继续开发。
