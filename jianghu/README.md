# 一人一江湖 · 江南初见

> 一人一江湖，万般皆人生。

这是一个纯 HTML/CSS/JavaScript 的浏览器可玩原型，无需安装依赖或构建工具。

## 启动
直接用浏览器打开 `index.html` 即可。也可在本目录运行任意静态文件服务器。

## 当前版本 0.1
- 江南水乡俯视角像素风地图与键盘移动（WASD / 方向键）
- 客栈、集市、茶摊老板、老渔翁等可交互地点/NPC
- 采集草药、枇杷；购买鱼竿并进行钓鱼
- 新手见闻任务、银两、声望、体力、背包与物品交易
- 时辰与动态天气
- 本地浏览器存档/读档（localStorage）

## 操作
- 移动：WASD 或方向键
- 交互：E
- 钓鱼/收竿：F（需先在集市购买鱼竿）
- 地图提示：M
- 也可使用界面按钮进行存档、休息、出售与调息

## Java 工程状态

Java 17 + Gradle + LibGDX 桌面工程位于本目录：

- `core/`：世界时钟、玩家、地图、任务、NPC 日程、关系与生活状态。
- `lwjgl3/`：桌面游戏启动器与地图渲染。
- `core/src/test/`：核心规则测试。
- `.github/workflows/jianghu-java.yml`：自动执行核心测试与桌面端编译。

运行桌面版本（需要 JDK 17 和 Gradle 8.10.2 或兼容版本）：

```bash
gradle :lwjgl3:run
```

NPC 的饥饿、精力、心情和职业收入会随游戏内时间推进；与玩家交谈会写入 NPC 的近期记忆。
